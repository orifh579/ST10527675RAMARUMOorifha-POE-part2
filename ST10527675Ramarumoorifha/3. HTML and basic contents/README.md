# techzonw electronics
## part 2 - CSS styling and responsive design
### project description
techzone electronics is a responsive websites designed to provide information about electronic products and services. part 2 focuses on improving the visual design, layout and responsiveness of the website using CSS.
## CSS styling
The websites uses an external CSS stylesheet called 'style.css'.
-apply consistent fronts, colours and spacing.
-style headings and paragraphs
-create a clear desktop layout using CSS flexbox/GRID.
-add borders, backgrounds and box shadows.
-add hover, focus and active effects to interactive elements.

## responsive design
Media queries were implemented to make the websites responsive on different screen sizes.
the website was tested on:
-desktop
-tablet
-mobile
the desktop version uses a multi-column layout, while smaller screens switch to a single-column layout.
relative units such as 'rem', 'em' and '%' were used to improve responsiveness.

## responsive images
responsive image techniques such as 'srcset'and 'sizes' were implemented so that suitable image sizes can be displayed on different devices.
